# Security policy

## Trusted preview

`electron-winui` is a pre-1.0 trusted preview. Only the latest preview release
candidate is considered for security fixes. No release currently has long-term
support or a guaranteed response or remediation time.

The tested runtime matrix and deployment boundaries are documented in
[SUPPORT.md](SUPPORT.md). A report outside that matrix is still welcome, but it
may require a reproducer on a tested configuration before it can be assessed.

## Report a vulnerability

Use GitHub's **Security > Report a vulnerability** flow for this repository.
Include the affected version or commit, Electron and Node.js versions, Windows
version and architecture, deployment mode, impact, and a minimal reproducer.

Do not disclose vulnerability details in a public issue. If private
vulnerability reporting is not available, open a public issue containing only a
request for a private maintainer contact channel. Enabling private vulnerability
reporting is an owner action tracked in
[the repository settings checklist](docs/repository-settings.md).

Please avoid accessing data that is not yours, degrading services, or publishing
details before maintainers have had a reasonable opportunity to investigate.
